MCCF Blogger proposal package

Files:
- MCCF_Blogger_Paste_Into_HTML_View.html: article body HTML to paste into Blogger's HTML view.
- mccf_emotional_mixing_board.png
- mccf_topology_modulation.png
- mccf_federated_architecture.png

Important image steps:
1. In Blogger, create a post and switch to HTML view.
2. Upload each PNG using Blogger's image tool. Blogger will host the images and provide image URLs.
3. In the HTML, replace:
   PASTE_BLOGGER_IMAGE_URL_MIXING_HERE
   PASTE_BLOGGER_IMAGE_URL_TOPOLOGY_HERE
   PASTE_BLOGGER_IMAGE_URL_ARCHITECTURE_HERE
   with the corresponding Blogger-hosted image URLs.
4. Paste the completed HTML into Blogger's HTML view and preview before publishing.

You can also paste the article HTML first, then use Blogger's editor to upload/insert the images at the indicated locations.
